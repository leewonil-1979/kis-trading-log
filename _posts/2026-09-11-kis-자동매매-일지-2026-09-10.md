## 6. 내일 점검 포인트

### 🔴 최우선 확인 사항
1. **신호 발생 여부 로그 검토**
   - 당일 스캐너가 정상 기동되었는지 실행 로그(`scanner.log`) 타임스탬프 확인
   - 신호 필터링 조건이 지나치게 엄격하게 설정되어 있어 0건이 된 것인지 파라미터 점검

2. **체결 및 잔고 동기화 상태 확인**
   - KIS API 응답 코드 및 웹소켓 연결 상태 이력 확인
   - 미체결 주문이 잔류하고 있는지 잔고·주문 내역 대조

3. **open 포지션 이월 여부 확인**
   - 전일 또는 당일 open 상태로 이월된 포지션이 존재하는지 확인
   - 해당 포지션의 청산 조건이 다음 거래일에 자동 적용되는지 검증

### 🟡 시스템 점검 사항
4. **데이터 파이프라인 정합성 검토**
   - 관찰 신호 0건·H3A 0건이 동시에 발생하는 경우, 데이터 수신 자체가 차단되었을 가능성 → 원천 데이터(시세 피드) 정상 수신 여부 확인

5. **가설 트리거 조건 재검토**
   - 모든 가설에서 진입 조건 미충족이 반복될 경우, 가설 파라미터의 시장 적합성 재평가 일정 수립

6. **다음 매매일 모니터링 기준 설정**
   - 당일과 동일하게 0건이 재발할 경우 알림(Alert) 발송 임계값 설정 여부 검토
   - 비거래일(공휴일·휴장) 여부를 사전 캘린더로 자동 필터링하는 로직 존재 여부 재확인
